Relatório — Apontamento JERP e Payload de Embalagens

Sistema: gde-insp-embalagem Data: 07/07/2026 Fonte: PostgreSQL (gdeembalagem) + OpActivityLog
Objetivo: Documentar a modificação do apontamento de produção no JERP (inclusão do array embalagens) e apresentar os payloads reais enviados nas últimas 5 caixas embaladas, com as respostas do JERP após finalização e impressão da etiqueta.

1. Resumo da modificação

1.1 Payload anterior

{
  "id": 430505,
  "quantidadeApontada": 48,
  "userName": "operador@gde.com.br"
}

1.2 Payload atual NOVO

{
  "id": 430505,
  "quantidadeApontada": 48,
  "userName": "operador@gde.com.br",
  "embalagens": [
    { "barcode": "07669100068" },
    { "barcode": "07669100067" }
  ]
}

O array embalagens contém um objeto { barcode } por blister embalado na caixa. O código vem do QR lido na inspeção (OpBoxBlister.code), ordenado por packedAt ASC.

2. Regras do apontamento

AspectoComportamento
Quando ocorreUma vez por caixa, após todos os blisters inspecionados
EndpointPOST {JERP_API}/ordemproducao
Origem dos dadosBanco PostgreSQL — nunca do frontend
quantidadeApontadaSoma de OpBoxBlister.quantity dos blisters com packedAt
embalagens[].barcodeQR do blister (OpBoxBlister.code)
O que não vaiID da caixa local, quantidade por blister, tipos de embalagem, imagens, PDF

3. Fluxo completo

Inspeção dos blisters → persistBoxStatusWithBlisters (banco local) → printTag() → POST /api/op-jerp/barcode → getAuthoritativeBoxPackedSummary (banco) → buildJerpEmbalagemApontamento (monta embalagens[]) → generateBarcode → POST JERP /ordemproducao → saveTagId (OpBox.barCode) → OpActivityLog (auditoria BARCODE_GENERATED) → Diálogo de impressão (idBarras + pdfBase64)

4. Resposta do JERP (impressão da etiqueta)

Após o apontamento, o JERP retorna PrintTagJerpDto:

{
  "message": "Apontamento realizado!!!",
  "id": 435055,
  "quantidadeApontada": 12,
  "idBarras": 1825522,
  "quantidadePendente": 1129,
  "descricao": "MODULO de DRL / POS / TI - LADO DIREITO - GM-00147",
  "pdfBase64": "<PDF da etiqueta em Base64>"
}

O pdfBase64 é usado para impressão; o idBarras é gravado em OpBox.barCode.
